# test_tools

Библиотека на Go для **тест-дизайна**. По списку параметров и их значений они генерируют готовые Excel-документы с тестовыми наборами:

- **ТПР** (таблица принятия решений) — полный перебор всех комбинаций.
- **Pairwise** (попарное тестирование) — минимальный набор тестов, покрывающий все пары значений. Это сокращает количество тест-кейсов.

## Что делает проект

Пользователь задаёт параметры, например: «Игра», «Версия», «Комплект», «Получение». У каждого параметра есть набор значений. Библиотека строит из них тестовые комбинации и сохраняет результат в Excel.

Консольного интерфейса нет: каждый пакет предоставляет `ReadTemplate(path)` и `Generate(params, cfg, outputFile)`, которые будет вызывать панель управления.

### Два пакета

| Пакет | Назначение | Листы в выходном файле |
|---|---|---|
| [`tpr`](tpr/tpr.go) | Таблица принятия решений. Строит все комбинации (декартово произведение). | «Таблица принятия решений» |
| [`pairwise`](pairwise/pairwise.go) | Попарное тестирование. Покрывает 100% пар значений минимальным числом тестов и считает, насколько сократился набор по сравнению с ТПР. | «Попарное тестирование», «Чек-лист», «Вывод по двум работам» |


## Технологии

- Go (модуль `test_design`)
- [excelize](https://github.com/xuri/excelize) (`github.com/xuri/excelize/v2`) — генерация `.xlsx`
