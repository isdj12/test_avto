# test_design

Консольные утилиты на Go для **тест-дизайна**. По списку параметров и их значений они генерируют готовые Excel-документы (`.xlsx`) с тестовыми наборами:

- **ТПР** (таблица принятия решений) — полный перебор всех комбинаций.
- **Pairwise** (попарное тестирование) — минимальный набор тестов, покрывающий все пары значений. Это сокращает количество тест-кейсов.

## Что делает проект

Пользователь задаёт параметры, например: «Игра», «Версия», «Комплект», «Получение». У каждого параметра есть набор значений. Программа строит из них тестовые комбинации и сохраняет результат в Excel.

### Две программы

| Файл | Назначение | Листы в выходном файле |
|---|---|---|
| [`tpr.go`](tpr.go) | Генератор таблицы принятия решений. Строит все комбинации (декартово произведение). | «Таблица принятия решений» |
| [`pairwise.go`](pairwise.go) | Генератор попарного тестирования. Покрывает 100% пар значений минимальным числом тестов и считает, насколько сократился набор по сравнению с ТПР. | «Попарное тестирование», «Чек-лист», «Вывод по двум работам» |

Обе программы — отдельные `package main` со своей функцией `main()` и общим набором вспомогательных функций. Это два независимых входа, а не один бинарник.

### Основные возможности

- Работают в интерактивном режиме. Спрашивают имя выходного файла, источник данных и режим расчёта ОР.
- Источник данных — файл-шаблон из `templates/` или ручной ввод в формате `Имя: Значение1, Значение2, ...`.
- Расчёт ожидаемого результата (ОР) для каждой комбинации, на выбор:
  1. сумма чисел;
  2. «умный» расчёт: `+100`, `-50`, `*1.5`, `+10%` от базы;
  3. произведение;
  4. порог: если сумма меньше X, то один текст, иначе другой;
  5. текстовое имя из значений параметров;
  6. фиксированный текст или пустые ячейки;
  0. не заполнять ОР.
- Оформление Excel: границы, шрифты, автоподбор ширины колонок, пояснения под таблицей.
- Pairwise-версия дополнительно выводит статистику: число полных комбинаций (ТПР), число тестов pairwise, число покрытых пар и процент сокращения.

## Структура проекта

```
test_design/
├── tpr.go                 # генератор ТПР (полный перебор)
├── pairwise.go            # генератор pairwise + чек-лист + вывод
├── templates/
│   ├── input_boardgames.txt   # пример шаблона: магазин настольных игр
│   └── v1.txt                 # короткий пример шаблона с числами
├── index.html             # пока пустой файл
├── go.mod / go.sum        # зависимости Go
```

## Формат шаблонов

Один параметр на строку: `Имя параметра: Значение1, Значение2, ...`

- Строки, начинающиеся с `#`, считаются комментариями.
- Числа в скобках используются для расчёта ОР: `(500)` — базовая цена, `(+200)` — прибавить, `(-50)` — вычесть, `(*1.5)` — умножить, `(+10%)` — прибавить 10% от базы.

Пример:

```
Игра: Взрывные котята (500), Бункер (700), Диксит (1200)
Версия: Детская (+200), Дорожная (+0), Настольная (+500)
Комплект: Да (+150), Нет (+0)
Получение: Самовывоз (+0), Доставка (+100)
```

Если шаблонов нет, программа создаёт шаблон по умолчанию `templates/input_boardgames.txt`.
